# TauxNet — Comparateur de crédit

Site comparateur d'offres de crédit avec affiliation CPL.

## Déploiement

1. Télécharger ce dossier
2. Créer un repo GitHub public "tauxnet"
3. Pusher les fichiers
4. Connecter à Vercel → importer le repo
5. Configurer tauxnet.fr dans Vercel → Domains
6. DNS Hostinger : A @ → IP donnée par Vercel

## Stack
- HTML/CSS/JS pur — aucune dépendance
- Hébergement Vercel (plan gratuit)
- Domaine Hostinger
